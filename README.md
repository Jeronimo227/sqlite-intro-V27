# ЛР 5. Вариант 27 — Читательские марафоны

## Тема

Программа работает с базой данных SQLite и таблицей `marathons`.

## Смысл полей

- `id` — уникальный номер записи;
- `name` — название читательского марафона;
- `category` — жанр;
- `value` — плановое количество страниц.

## Запуск

```bash
python main.py
```

## Выполненные операции

- Создание таблицы `marathons`.
- Добавление 8 исходных записей.
- Вывод всех записей.
- Выбор записей категории «Фантастика».
- Фильтр `value > 200`.
- Сортировка по `value` по возрастанию.
- Изменение количества страниц у записи с `id = 2`.
- Удаление записи с `id = 5`.
- Сохранение изменений в файле `app.db`.
